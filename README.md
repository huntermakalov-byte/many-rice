# 🌾 ระบบจัดการร้านค้า & POS "นานาข้าว" (Nana Khao POS)

ระบบ POS สำหรับร้านค้าขายนานาข้าว ข้าวสารคัดพิเศษ และเมนูข้าวซิกเนเจอร์ พัฒนาด้วย React + Vite ออกแบบให้พร้อม Deploy บน **Vercel** ทันที และเชื่อมต่อฐานข้อมูลบนคลาวด์ด้วย **Supabase**

---

## ✨ ฟีเจอร์หลักของระบบ

1. **จุดขายหน้าร้าน (POS Frontend)**
   - แคตตาล็อกสินค้าพร้อมฟิลเตอร์หมวดหมู่ (ข้าวสารพรีเมียม, เมนูข้าวซิกเนเจอร์, เครื่องดื่ม & ของหวาน)
   - ค้นหาสินค้าแบบเรียลไทม์ พร้อมแสดงสต็อกคงเหลือ
   - ระบบตะกร้าสินค้า (เพิ่ม/ลดจำนวน, ลบรายการ, เลือกว่าทานที่ร้านหรือสั่งกลับบ้าน, บันทึกชื่อลูกค้า/โต๊ะ)
   - คำนวณยอดเงินรวม ส่วนลด และยอดสุทธิอัตโนมัติ

2. **ระบบการชำระเงิน (Payment)**
   - **เงินสด (Cash):** ปุ่มลัดระบุเงินที่รับมา (พอดี, 100, 500, 1000) พร้อมคำนวณเงินทอนอัตโนมัติแบบเรียลไทม์
   - **QR Code พร้อมเพย์:** ระบบสร้าง PromptPay QR Code จริงตามมาตรฐาน EMVCo พร้อมยอดเงินและชื่อร้าน
   - เอฟเฟกต์ Confetti เฉลิมฉลองเมื่อสั่งซื้อสำเร็จ
   - **ใบเสร็จรับเงิน (Printable Thermal Receipt):** สลิป 80mm พร้อม QR Code ตรวจสอบ สามารถสั่งพิมพ์ (Print) หรือบันทึกได้ทันที

3. **แดชบอร์ดสรุปยอดขายรายเดือน (Monthly Dashboard)**
   - ตัวกรองเลือกดูตามเดือน/ปี
   - บัตรสถิติ KPI: ยอดขายรวมประจำเดือน, จำนวนบิล/ออเดอร์, ยอดเฉลี่ยต่อบิล, จำนวนลูกค้าที่เข้าใช้บริการ
   - กราฟแท่งแนวโน้มยอดขายรายวัน (Daily Sales Bar Chart) พร้อมไฮไลท์วันที่ขายดีที่สุด
   - สรุปสัดส่วนช่องทางชำระเงิน (เงินสด vs QR Code)
   - 5 อันดับสินค้าขายดีที่สุดประจำเดือน
   - ตารางประวัติออเดอร์พร้อมปุ่มเปิดดูใบเสร็จย้อนหลัง
   - ปุ่มส่งออกรายงานเป็นไฟล์ **CSV**

4. **ระบบหลังบ้านสำหรับแอดมิน (Admin Backoffice)**
   - เพิ่มสินค้าใหม่ (ชื่อ, หมวดหมู่, ราคาขาย, ราคาทุน, สต็อก, คำอธิบาย, รูปภาพ)
   - แก้ไขข้อมูลสินค้าและปรับราคา
   - จัดการสต็อกด่วน (+5, -1)
   - ลบสินค้าที่ไม่ต้องการ

5. **บันทึกการเข้าใช้งานของลูกค้า (Customer Logs)**
   - แบบฟอร์มบันทึกการเข้าใช้บริการ (ชื่อลูกค้า, เบอร์โทร, รูปแบบการเข้าใช้, ยอดใช้จ่าย, บันทึกความชอบ/โน้ต)
   - บันทึกการเข้าใช้งานอัตโนมัติทันทีที่มีการเปิดบิลสั่งซื้อ
   - สถิติจำนวนครั้งที่เข้าใช้, จำนวนลูกค้าไม่ซ้ำ, และยอดใช้จ่ายสะสม
   - ตารางประวัติการเข้าใช้งานพร้อมค้นหา

## 🚀 การติดตั้งและเริ่มใช้งานในเครื่อง (Local Setup)

```bash
# 1. ติดตั้ง Dependencies
npm install

# 2. รันโหมด Development
npm run dev
```

เปิดบราวเซอร์ที่: `http://localhost:5173/`

## 🗄️ การตั้งค่าฐานข้อมูล Supabase

1. สร้างโปรเจกต์ฟรีที่ [Supabase](https://supabase.com)
2. เข้าไปที่เมนู **SQL Editor** ในแดชบอร์ด Supabase
3. คัดลอกโค้ดทั้งหมดจากไฟล์ `supabase_schema.sql` ในโฟลเดอร์นี้ ไปวางใน SQL Editor แล้วกด **Run**
4. ไปที่ **Project Settings > API** เพื่อคัดลอก:
   - `Project URL`
   - `anon public key`
5. นำค่ามาใส่ในไฟล์ `.env` ในโปรเจกต์:
   ```env
   VITE_SUPABASE_URL=https://your-project-id.supabase.co
   VITE_SUPABASE_ANON_KEY=your-anon-key-here
   ```
   *หรือสามารถกดที่ปุ่มสถานะ Supabase บนแถบเมนูในหน้าเว็บเพื่อกรอกและทดสอบการเชื่อมต่อได้โดยตรง!*

## 🌐 การ Deploy ขึ้น Vercel

1. อัปโหลดโค้ดขึ้น GitHub Repository
2. เข้าสู่ระบบที่ [Vercel](https://vercel.com) แล้วเลือก **Add New > Project**
3. นำเข้า (Import) Repository ของคุณ
4. ในส่วน **Environment Variables** ให้เพิ่ม 2 ค่า:
   - `VITE_SUPABASE_URL`: URL ของโปรเจกต์ Supabase
   - `VITE_SUPABASE_ANON_KEY`: Anon Key ของ Supabase
5. กด **Deploy** — Vercel จะ Build และ Deploy ให้ทันทีผ่านไฟล์ `vercel.json` ที่ตั้งค่ารองรับ SPA ไว้แล้ว
